# 🔊 Sound Words

**Turn the words in SillyTavern into interactive sound triggers.**

Sound Words lets you assign local audio files to words or word combinations that appear in SillyTavern messages. When a trigger appears, the matching word becomes clickable and plays the sound you assigned, making the text itself part of the audio experience.

## ✨ What can you do?

- Assign one or multiple audio files to the same trigger.
- Randomly choose between multiple sounds.
- Set an individual volume for each sound.
- Play multiple sounds simultaneously.
- Include user messages as well as character messages.
- Use **specific-word triggers** for simple matches.
- Use **word-combination triggers** such as `knocks+side+fist` for more specific contextual sounds.
- Use music or entire custom playlists as triggers.
- Build your own sound library for virtually anything that happens in your RP.

### Word combinations

Word combinations do not need to appear next to each other. For example:

> *The bus stopped hissing, and the doors opened.*

A trigger such as `doors+bus` can match both words within the same sentence, even though they are separated by other words and punctuation such as commas.

This also allows more specific triggers such as:

> *She knocks again with the side of her fist this time.*

`knocks+side+fist`

This makes it possible to use a different sound for a much more specific action while keeping `knocks` available as a general trigger.

## 📦 Installation

Sound Words works with SillyTavern's normal **third-party extension installer**.

1. Open SillyTavern.
2. Go to **Extensions**.
3. Open **Install Extension**.
4. Paste this repository URL:

```text
https://github.com/ganbuscovick/Sound-Words
```

5. Install the extension.

For information about SillyTavern itself, see the official repository:

https://github.com/SillyTavern/SillyTavern

## 📱 Compatibility

Sound Words is designed to be universal and works on **PC and mobile**.

It was primarily tested on **Android/mobile**, so mobile use is fully supported.

On mobile, if the audio controls do not appear correctly while using **landscape mode**, simply rotate the screen to **portrait mode**.
