Sound Words

Turn words in SillyTavern into interactive sound triggers.

Sound Words lets you assign local audio files to words or word combinations that appear in SillyTavern messages. When a trigger appears, it becomes clickable and plays the sound you assigned, turning the text itself into an interactive audio layer.

What can you do?

You can assign one or multiple audio files to the same trigger, randomize between them, set individual volume levels, play multiple sounds simultaneously, include user messages, and use either specific-word triggers or word-combination triggers such as "knocks+side+fist" for more precise contextual sounds. Music and entire custom playlists can also be used as triggers.

Installation

Install the extension through SillyTavern's normal third-party extension installer using the GitHub repository URL.

Sound Words is universal and works on both PC and mobile. It was primarily tested on Android/mobile, so mobile usage is fully supported.

On mobile, if the audio controls do not appear correctly while using landscape mode, simply rotate the screen to portrait mode.
